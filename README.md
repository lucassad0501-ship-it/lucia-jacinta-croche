# Lúcia Jacinta Crochê — V2.1 corrigida

Loja e painel demonstrativo, com CSS incorporado em `index.html` e `admin.html` para evitar falha no carregamento de estilos.

## Publicação no GitHub
Envie os 7 arquivos deste pacote diretamente à raiz do repositório, substituindo os de mesmo nome.
Remova os arquivos antigos `style.css` e `painel.html` **somente depois de verificar que não há outros arquivos ou links dependendo deles**. Não mantenha a pasta da versão antiga nem o ZIP dentro do repositório.

## Atenção
O painel não possui autenticação. Os dados são salvos apenas no localStorage de cada navegador e não sincronizam com outros dispositivos. Não use para administrar vendas reais. Os produtos e estoques iniciais são demonstrativos. A finalização é apenas um pedido de contato via WhatsApp; não há pagamento Pix ou checkout.

Se o navegador já tiver dados locais da V2, eles serão mantidos porque a chave de armazenamento não mudou. Antes de alterações importantes, exporte o JSON no painel.
